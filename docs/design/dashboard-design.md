## 0. 定位与总原则

**一句话定位**：一位每天上班的 AI 黄金分析师，加一套保证底层事实稳定准确的规则程序。产出一页每日更新的仪表盘，供你与小范围朋友阅读参考。

**使用场景**：自己及朋友小范围使用，日度追踪，持仓周期数周到数月。锚定 XAUUSD，实际交易标的为 GC、GLD、GDX 与 GDXU。以中期（3 个月）为主视图，短期（数周）与长期（12 个月）为辅。

**分工原则**（由你在讨论中确立）：

| 角色 | 负责 | 不负责 |
|---|---|---|
| 规则程序 | 封闭式问题：抓数据、计算指标与分位、监控信号与异动、核对可量化的证伪条件、写日志、做审计。目标是底层信息的稳定与准确 | 任何需要综合的判断 |
| AI 分析师 | 开放式命题：叙事状态、定价程度、张力、情景与概率、方向与信心与失效条件、新闻解读、反方论证、叙事调研。每条判断必须引用具体数据或链接 | 抓数与算数 |
| 你 | 只读参考，可选覆盖 | 不做定级，不做确认，不是流程的必经环节 |

**验真证伪的三种处理**：
1. 可量化且边界清晰：写成“指标、比较符、阈值、截止日”，程序每日自动判定。
2. 可量化但边界模糊：程序给出数值、趋势与区间提示，AI 结合上下文判定并写明理由。
3. 只能定性：AI 判定并写明理由与引用。
三种结果都写入日志并计入 AI 的校准评分。不强行把定性命题量化。

## 3. L1 指标体系：由叙事决定，由注册表驱动

### 3.0 指标体系如何确定

金价由大量跨市场、跨资产指标经叙事演绎与博弈形成，所以**选哪些指标由叙事调研决定，不由本文档预先固定**。具体机制：

1. **注册表驱动**。每个指标是 `indicators/registry.yaml` 里的一条配置：来源、序列号、频率、发布滞后、计算方式、所属因子组、为哪些叙事作证及预期方向。程序按注册表抓取与计算，增删指标只改配置，不改代码。
2. **种子集只为打通管道**。下文 3.2 到 3.8 的约 30 个指标是第 1 阶段的种子，用于把适配器、计算、渲染跑通。它们是黄金定价的经典变量，预计大部分会保留，但保留与否由第 3 条决定。
3. **调研交付指标规格**。第 0 阶段调研的正式产出之一是指标规格：每条叙事挂哪些证据指标、预期方向、优先级、数据来源（见 `docs/research/gold-pricing-logic-2026-09.md` 第三部分与附录 `docs/research/appendix-narrative-library-2026-09.md` 第 6 节）。**指标到叙事的映射由叙事卡的证据字段自动生成，注册表不重复维护**，避免两处漂移。第 2 阶段按该规格完成正式映射与增删。到那时仍答不上“为哪条叙事作证”且不属基线或标的监控的种子指标删除。
4. **指标分级**。一级指标常驻保留并优先关注，二级指标用于阐述与佐证叙事，三级为背景与观察池，规则见 3.1。一级的设立理由来自 8/31 的教训：旧锚在体制切换时会立即回归，只按当前叙事选指标会在切换发生时失明。

每个指标一律显示历史分位、日周变动、数据截止日与滞后。分位数基于官方来源能拿到的最长历史，上限 10 年。

### 3.1 指标分级

分级解决的是**注意力分配**问题：叙事很多且来回切换，但每天能认真看的指标有限。级别与叙事映射是注册表里两个独立的属性：一级指标同样可以为叙事作证，二级指标也可能连续数月活跃。

| 级别 | 定义 | 判定标准 | 增删权限 |
|---|---|---|---|
| 一级 常驻 | 黄金定价的体制仪表，回答“现在处于哪种体制、旧锚是否在起作用、市场有多拥挤” | 跨体制稳健的定价关系；官方日频数据，央行购金为低频例外；缺了它就无法察觉体制切换 | 只能由调研或人工修改，版本化留痕，AI 不能改 |
| 二级 叙事证据 | 为某条或几条活跃叙事作证 | 被至少一条活跃叙事卡的证据指标字段引用 | 随叙事生命周期自动激活或休眠 |
| 三级 背景与观察池 | 低频结构性数据；已归档叙事留下的休眠指标；调研提出但尚未映射的候选 | 其余 | 自动 |

**级别决定的行为**

| 行为 | 一级 | 二级 | 三级 |
|---|---|---|---|
| 采集与分位计算 | 全部 | 全部 | 全部 |
| 页面位置 | 顶部行情台固定 | 挂在所属叙事卡下，叙事活跃才展开 | 折叠区 |
| 异动提醒 | 始终 | 所属叙事活跃时 | 不提醒，仅记录 |
| AI 输入包 | 始终全量 | 活跃叙事所属 | 仅摘要 |

**退出展示不停止采集**。叙事来回切换，二级指标随叙事休眠时只是不再展示与提醒，数据继续每日采集，分位数历史不断档。叙事回归时 AI 可提议重新激活，历史完整可用。

**一级指标的建议初值**，约 15 个，最终由调研确认：金价基准（LBMA 下午定盘价、COMEX 结算价、连续报价）、10Y TIPS 实际收益率、10Y 盈亏平衡通胀、2Y 与 10Y 与 30Y 名义收益率、2s30s 斜率、美元指数、政策路径（由联邦基金期货复算的各次 FOMC 概率分布）、GVZ 及 GVZ/VIX 比、VIX、CFTC 管理基金净多分位、GLD 持仓变动、200 日均线距离与动量、央行购金（低频常驻）。

**标的监控组**：GDX、GDXJ、GDXU 及其派生指标是交易标的，常驻显示但不参与叙事证据，单列在行情台末尾。

### 3.2 数据质量硬规则

1. **只用官方或一手来源的正式发布值**。来源优先级：官方发布机构（FRED 与美联储、美国财政部、CFTC、CME、SPDR、WGC、上金所、上期所、LBMA）高于交易所数据的常规分发商（Yahoo、Stooq，用于连续行情与期货合约）。新闻稿、研报、网页文章中引用的行情数字一律不得作为指标值。
2. **每个数据点带完整出处**：来源、序列号或合约代码、数据截止日、抓取时间、发布滞后。页面上每个数字可追溯。
3. **“最新”指最新一次正式发布**，不是实时。COT 滞后三天、WGC 滞后一到两个月之类的固有滞后直接标在指标卡上，永远不把旧数据当成新证据展示。
4. **金价的官方基准**：日度基准优先用 LBMA 下午定盘价与 COMEX GC 官方结算价，连续行情用 Yahoo 或 Stooq 并标注“连续报价”。LBMA 数据的免费可得性在第 1 阶段确认。
5. **AI 不得引入快照之外的数字**。程序校验 AI 输出中的数值，凡在当日数据快照中找不到的退回重写。AI 读新闻只为识别事件与解读，不为取数。
6. **来源变更留痕**。任何指标换源、改算法都记录在注册表的版本历史中，并在页面口径说明里标注生效日期。

## 4. 叙事库与叙事卡

叙事库是 `narratives/` 目录下的 YAML 文件，每条叙事一个文件，由第 0 阶段调研生成初版，之后由 AI 分析师每日更新。生命周期状态：新兴、边际、主导、共识、退潮、已证伪、归档。定价程度：未定价、部分、充分、已出清。

### 4.1 叙事卡字段
| 字段 | 说明 | 由谁维护 |
|---|---|---|
| id、name | 标识与名称 | 调研阶段确定 |
| thesis | 命题，一句话 | 调研 |
| logic_chain | 逻辑链 | 调研 |
| direction | 对金价方向：多、空、中性 | 调研 |
| horizon | 时间尺度 | 调研 |
| regime_dependency | 在“联储被动”与“联储主动可信”两种体制下方向是否反转。这是 8/31 更新的核心教训 | 调研 |

| sources | 建卡依据的一手来源 | 调研 |

### 4.2 状态迁移规则
- AI 每日看到昨日全部卡片，输出每条卡的“维持”或“变更”。变更必须引用日期不早于昨日的新证据。
- 同一变更连续两日出现才正式生效，生效当日写入叙事日志。
- 量化证伪条件由程序判定，命中当日立即标注“已证伪”并归档，不受两日惯性限制。定性证伪条件由 AI 判定并写理由，同样立即生效。
- 证伪条件不可覆盖，修改只能追加新版本并写理由，页面显示全部版本。
- 你可以直接编辑 YAML 覆盖任何字段，程序检测到人工改动后标注“人工覆盖”并保留 AI 原判断。
- AI 可新增叙事卡，初始状态为“新兴”，必须含完整字段与至少一条证伪条件。

## 5. AI 分析师的输入输出契约

### 5.1 输入包（由程序组装为单一上下文）
1. 指标快照：一级指标全量，二级取活跃叙事所属，三级仅摘要。每个指标含当前值、日周变动、分位、z 分、异动标记、数据截止日与滞后。
2. 规则检测结果：背离清单（预定义矛盾组合，如“实际利率上行但金价不跌”“ETF 流出但金价上涨”）、相关性破裂、分位极值、量化证伪条件的核对结果。
3. 叙事库昨日状态：全部卡片。
4. 事件日志新增：RSS 与 Google News 聚合的标题摘要（含来源与链接）、未来两周事件日历（FOMC、CPI、PCE、国债拍卖、COT 发布、WGC 发布）。
5. 近期 AI 输出摘要（保持连续性）。
6. AI 自主联网检索：按每张叙事卡的监控查询词，每日设上限；每条结果记录 URL 与时间。

### 5.2 输出（结构化 JSON，程序做 schema 校验，不合格退回重写）
| 字段 | 内容 | 校验 |
|---|---|---|
| today_summary | 三句话结论 | 非空 |
| narrative_updates | 每条叙事的状态、定价程度、证据动能、张力备注，各带 evidence 引用 | 每条判断至少一个引用；变更必须有新证据 |
| new_narratives | 新叙事卡提案 | 字段完整，至少一条证伪条件 |
| divergence_notes | 每条背离的候选解释 | 引用 |
| qualitative_judgments | 定性验证与证伪条件的判定与理由 | 引用 |
| scenarios | 五个情景：名称、条件、概率、3 个月目标区间、依赖叙事、触发信号 | 概率求和为 1 |
| stance | 方向、信心等级、失效条件、依赖叙事 | 失效条件必须引用具体指标 |
| counterargument | 对当前最强叙事的最强反方论证 | 非空 |
| next_watch | 接下来最重要的信号与日期 | 非空 |
| prose | 各区块的解读文字 | 长度上限 |

程序在 AI 输出之后完成封闭式计算：期望收益、赔率、偏度、情景与叙事的依赖标红。AI 不做算术。

### 5.3 运行方式
- Claude Code 无头模式，提示词版本化存于 `prompts/`，模型固定并记录在每次运行日志中。
- 写作步骤封装为适配器接口，日后可切换到 Anthropic API 或云端定时任务。
- AI 失败时发布“仅数据”版本页面并显著标注“今日 AI 分析未生成”，绝不静默发布错误内容。

### 5.4 AI 校准审计
- 短期情景分支到期后由程序核对兑现情况，累计 Brier 分与命中率。
- 状态变更的事后回看：变更后 20 与 60 个交易日的金价与证据走势。
- 校准分显示在 L4 区块，随时间积累。

## 11. 我可能错在哪

- **AI 判断的日间一致性**：两日惯性会滞后一到两天，遇到 8/28 那种单日体制切换可能反应偏慢。缓解：证伪命中不受惯性限制，且异动清单当日即显示。
- **免费数据源的稳定性**：Yahoo 接口时有变动；Stooq 的下载接口已加 JS 人机验证，不能作为无人值守备用源，行情备用源在第 1 阶段另定（候选：CME 每日结算公开文件、Nasdaq Data Link 免费数据集）。缺失一律标记而非静默。
- **主流媒体的可得性**：只有标题与摘要，可能漏掉付费墙后的关键细节。缓解：AI 联网检索二手转述；必要时升级付费 API。
- **无头模式的配额与联网稳定性**：若每日运行受限，切换到 API 适配器。
- **公开链接**：任何拿到链接的人都能读。若介意，二期加访问控制。
- **矿业股组的数据深度**：AISC 与利润率为季频且需手工整理，一期可能只有价格类指标。
